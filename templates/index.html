API Key Management

Keys are encrypted with Fernet (AES-128-CBC) and stored locally in secrets.json. They are loaded into the process environment on every app start. The plaintext value is never sent back to the browser.

Hinweis: The encryption key (secrets.key) is stored on the same machine. Anyone with server access can decrypt the file. Make sure your Armbian server is properly secured (firewall, SSH key auth).
